# Tool Box — Android project

این پروژه نسخه اندرویدی Tool Box است و فایل‌های وب را داخل WebView به صورت آفلاین اجرا می‌کند.

## ساخت APK در Android Studio
1. Android Studio را نصب کنید.
2. گزینه **Open** را بزنید و همین پوشه `ToolBox-Android` را انتخاب کنید.
3. صبر کنید Gradle Sync تمام شود.
4. از منوی **Build > Build APK(s)** استفاده کنید.
5. APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
